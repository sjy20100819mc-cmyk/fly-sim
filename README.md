# 果蝇 3D 模拟器 · FlyWire FAFB v783 连接组约简脉冲脑

一个**纯前端、离线可跑**的果蝇自主行为模拟器：每只果蝇都有一副从真实全脑连接组约简出来的**脉冲神经网络**（LIF），行为不是脚本写死的，而是从回路里长出来的。

![预览](docs/preview.jpg)

## 直接玩

- **在线版（3D）**：`index.html` — 打开即玩，无需安装任何东西
- **在线版（2D）**：`fly-sim.html` — 更轻量
- **纯规则版**：`fly-sim-simple.html` — 便于阅读与魔改

想本地跑：把 `index.html` 下载下来双击即可（three.js 已内联，**完全离线**）。

## 它凭什么"像果蝇"

行为内核参考了目前最新一代开源果蝇全脑工作：

| 来源 | 用到的部分 |
|---|---|
| **FlyWire FAFB v783 (Codex)** — 成虫全脑连接组，139,255 神经元 / 2.7–3.7M 边（*Nature* 634:124-138, 2024） | 细胞类型命名、接线逻辑、**≥5 突触才建边**惯例 |
| **brandoncho369/flybench** (2026) — 全脑仿真的反射基准套件 | 参考 LIF 参数 `w_syn=0.275`、全局 `gain≈0.42`（0.40–0.45 为反射通过区）、反射判据 |
| **philshiu/Drosophila_brain_model** — 首个全脑 LIF 模型（*Nature* 2024, Brian2） | LIF 神经元 + "刺激感觉神经元 → 读运动神经元"范式 |
| **Neuromorphicism/fly-brain-snntorch** | 稀疏脉冲实现与多感官通道 |
| **snedea/flybrain** — 浏览器端 139K LIF 实时仿真 | Sensory / Central / Drives / Motor 分组、以放电率读出行为 |
| **NeLy-EPFL/flygym (NeuroMechFly v2)** | 具身观：DN 下达指令 + VNC 局部反射环 |

手机浏览器跑不动 13.9 万神经元 × N 只果蝇，所以做**连接组约简**：保留行为关键回路的细胞类型、递质符号与接线，**每只果蝇一副 71 神经元的 LIF 脉冲网**
（cuLIF，τm=20 ms，τsyn=5 ms，2 ms 不应期，含放电频率适应），权重 `w = w_syn · gain · K · 每对突触数`。

### 回路 → 行为

| 行为 | 通路 |
|---|---|
| 饥饿驱动觅食 | Hugin(SEZ) → LHON↑ / MN_walk↑ ＋ 抑制 MBON_av（越饿越冒险） |
| 气味吸引 | ORN → PN → LHON → DN_walk；PN → KC → MBON_app |
| **惩罚性学习** | 气味(CS，KC 活动) × DAN_PPL1(PPL1 多巴胺，过阈值才门控) → **KC→MBON_av 权重↑** → 从此绕行粘板 |
| 奖赏性学习 | GRN_sugar → DAN_PAM → KC→MBON_app 权重↑ |
| 记忆消退 | 闻到气味但无惩罚 → 权重缓慢回落（extinction） |
| 警戒信息素避害 | 被粘个体持续释放 → 同伴 ORN_alarm → MBON_av / DN_escape → 回避＋逃逸 |
| 逃逸反射 | 突现 visual / 机械冲击 → DN_escape(DNa01/02，巨纤维) → MN_walk 爆发 |
| 取食 | GRN_sugar → MN_feed(MN9 喙伸展)；FB 饱足信号抑制 |
| 稀疏编码 | KC → APL → KC 反馈抑制（蘑菇体前侧成对侧神经元） |

> 多巴胺按**纯调质**处理：DAN 的出边权重为 0，只门控可塑性（不参与快速电流）。

### 内建反射自检（对照 flybench 判据，实测全通过）

| 检查 | 实测 |
|---|---|
| 静默 → 静默 | 0.00 Hz（判据 < 0.5 Hz） |
| 糖 → MN9 喙伸展 | 21 Hz（判据 > 5 Hz） |
| 警戒抑制糖反应 | 8 Hz（判据 < 糖反应一半） |
| 突现 → 巨纤维逃逸 | 29 Hz（判据 > 10 Hz） |
| 气味 → 行进 | 29 Hz |

## 玩法

- 🍎 **食物**：果蝇被气味吸引，落到食物上才会取食（MN9 放电 → 喙伸展）
- 🟨 **粘板**：发酵气味诱惑 → 接触被粘住（挣扎、释放报警信息素，同伴回避）→ 侥幸弹开者把"这里危险"写进蘑菇体，从此绕行
- 🪰 投蝇 ｜ 🧽 清除 ｜ 🧠 脑活动（看某只果蝇此刻神经元放电与已学到的危险权重）｜ 👃 气味场
- **3D 版操作**：单指拖动旋转 · 双指捏合缩放 · 轻点地面放置 · **轻点果蝇追踪观察** · 🎥 视角切换 · 📷 快照分享
- 悬停/点选果蝇可看它的内部状态（饥饿度、活跃细胞类型、学习指数、读出放电率）

## 调参

网页里点 **⚙︎ 参数**，所有参数实时生效（速度、代谢、繁殖率、信息素强度、多巴胺学习率、全局 gain……）。
完整参数表与改造指南见 [`src/PARAMS.md`](src/PARAMS.md)。

想加一种神经元：在 `CTYPE` 加一行 `[名字, 分组, 符号, 数量, 说明]`，再在 `CONNECTIONS` 里按 `[前, 后, 突触总数]` 接线即可——
`突触总数 /(前群数 × 后群数)` 就是"每对突触数"，参考 FAFB 量级：强连接 5–20、弱连接 1–4。

## 性能

90 只果蝇时：仿真实例化 ~1.3 ms/帧、28 draw call。果蝇数 > 70 会自动把脑步数降为每帧 1 步；老设备可下调 `pop.max`。
